# AI-Assisted Construction Accounting Suite

A standalone bookkeeping and financial management platform designed for construction businesses.

## Features

- Expense tracking
- Receivables management
- GST/HST reporting
- General Ledger exports
- Trial Balance generation
- Income Statement reporting
- Salary GL account management
- Financial dashboard analytics

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser local storage
- CSV export automation

## Purpose

This project was developed to streamline bookkeeping and operational accounting workflows for a construction company through automation and workflow-focused design.
